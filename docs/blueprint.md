# **App Name**: StreamDeck TV

## Core Features:

- Channel Fetching: Fetch live TV channel data from the specified GitHub repository.
- Live Streaming: Play the selected live TV stream in full-screen mode.
- Favorite Channel: Allow users to mark channels as favorites for quick access.
- Channel Navigation: Display available channels as small thumbnails when the down button is pressed, allowing easy navigation.

## Style Guidelines:

- Primary color: Dark slate blue (#37474F) for a professional look.
- Background color: Very dark gray (#263238), almost black, for good contrast in a dark scheme.
- Accent color: Teal (#008080) to draw attention to important elements.
- Body and headline font: 'PT Sans', a modern-looking sans-serif, for headlines and body text
- Simple, clear icons for channel selection and playback controls.
- Full-screen video playback with minimal UI elements to avoid distraction.
- Smooth transitions for channel changes and UI element появления/изчезновения.
