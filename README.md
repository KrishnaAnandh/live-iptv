# StreamDeck TV

This is a Next.js application for streaming live TV channels, designed for Android TV and Google TV platforms.

A native **Google TV / Android TV** app lives in [`android/`](android/). See [`android/README.md`](android/README.md) for build, install, and sideload instructions.

To get started with the web app, run the development server:

```bash
npm run dev
```

This will start the app, which fetches a list of IPTV channels and allows you to stream them.
